# SaymonTools

Файловый конвертер для Windows с круговым меню. Основан на открытом проекте [Sweetch](https://github.com/krllmrzv/Sweetch) (MIT).

Перетащите файл и нажмите **Shift** для конвертации, **Ctrl** для инструментов или **Alt** для действий. Отпустите файл над нужным сектором. Для работы без мыши выберите файлы в Проводнике и нажмите **Ctrl + Alt + Space**.

## Запуск

Распакуйте весь архив и запустите `SaymonTools.exe`. Программа находится в области уведомлений рядом с часами; двойной щелчок открывает настройки. Требуется Windows 10 (1809+) или Windows 11, x64. .NET включён в переносную сборку.

Настройки хранятся в `%APPDATA%\SaymonTools`, загружаемые инструменты — в `%LOCALAPPDATA%\SaymonTools\tools`. Скриншоты и виртуальные вложения сохраняются в `Downloads\SaymonTools`. Исходные файлы не перезаписываются.

## Форматы

Изображения, аудио, видео, PDF, документы, таблицы, презентации, субтитры и архивы. Доступные операции зависят от типа входного файла. Pandoc включён в архив. Для аудио и видео FFmpeg скачивается через настройки; LibreOffice для части операций Office/PDF устанавливается отдельно. Обработка файлов локальная: в интернет файлы отправляются, только если выбрать «В интернет».

## Ссылки на файлы

Действие **«В интернет»** (Alt) загружает файл на бесплатный сервис без регистрации — temp.sh (до 4 ГБ, 3 дня), Gofile или Litterbox (до 1 ГБ, от 1 часа до 3 дней; из некоторых сетей не принимает файлы) — и показывает ссылку с QR-кодом; ссылка сразу копируется в буфер обмена. Несколько файлов или папка загружаются одним ZIP. Если выбранный сервис не отвечает, используется следующий. Файл доступен любому, у кого есть ссылка. Сервис и срок хранения выбираются в настройках.

## Сборка

Нужен .NET SDK 10. В PowerShell из папки проекта:

```powershell
./build.ps1
dotnet test tests/SaymonTools.Tests -c Release
./publish/SaymonTools.exe --self-test ./self-test
```
